# test2 Package

This folder contains the **`test2`** testing suite and verification modules.

---

## 📁 Contents

- `__init__.py`: Package export.
- `test_suite.py`: 7 comprehensive unit test cases covering:
  - Dynamic hazard obstacle placement and real-time AMR detours
  - Automated battery depletion and recharging thresholds
  - Inventory management, order fulfillment, and stock deductions
  - Cardiac hemodynamic systolic/diastolic pressure models
- `main.py`: Executable runner inside this folder.

---

## 🚀 How to Run

From inside the `test2/` folder:
```bash
python3 main.py
```

From the root project directory:
```bash
python3 -m unittest test2.test_suite
```
